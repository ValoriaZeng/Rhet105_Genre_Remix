# ⚖️ Designing Future - Visual Novel Game
## 📑 Game Description
Designing Future is a visual novel game that creates a court environment for the debate of ethical issues in gene editing. In the game, the player will act the role of defendant, who is a mystery scientist in gene editing area.
You will have a exciting conversation with the Judge, Prosecutor, and your college, the Defense, to explore the future of this technology!
## 🎮 How to Play
- **Correctly Install** the game (See Instructions Below!!!)
- Follow the instructions in the game
- Enter your **name**
- If you want to see your previous score, enter the same name every time
## System Requirements
This game is built with the Unity Engine and is designed to run smoothly on most modern desktop systems.
- Operating System: Windows 10/11 or macOS 10.15+ (Catalina or newer)
- Processor: 1.6 GHz or faster
- Memory: 4 GB RAM
## Installation and Launch
### 🚀 Windows (Suggested)
1. Downlaod the game file ```DesigningFuture.zip```  
2. Unzip the file  
3. Run the main executable file ```DesignFuture.exe```
### 🍎MacOS
1. Download the game file ```DesigningFuture_Mac_Version.app.zip```
2. Unzip the file
3. Run the ```DesigningFuture_Mac_Version.app```
> [!Warning]
> If the game was built on a Windows computer, macOS may remove the necessary permissions needed to run the application. If you see the error "The application 'DesigningFuture.app' can't be opened," follow these steps to fix the permissions:
> 1. **Open termial**: Go to **Applications** > **Utilities** > **Terminal**
2. **Navigate to the File**: Type the following command and press Enter (assuming the game is in your Downloads folder):  
```cd ~/Downloads```
> [!Note]
> Replace the "Downloads" with your own folder name
3. **Apply the Fix**: Copy and paste the two commands below:  
```
Command 1: xattr -cr "DesigningFuture_macVer.app  
This removes quarantine status that sometimes blocks apps  
Command 2: chmod +x "DesigningFuture_macVer.app/Contents/MacOS/DesigningFuture"  
This sets the required executable permission
```
4. **Launch:** You should now be able to double-click and run the application normally
